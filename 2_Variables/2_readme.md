## <font color="gree">Variáveis em C++</font>
As variáveis são contêineres para armazenar valores de dados. Em `C++`, existem diferentes tipos de variáveis (definidas com diferentes palavras-chave), por exemplo:

| Tipo de Variável | Descrição | Exemplo de Uso |
|------------------|-----------|----------------|
| int | Armazena números inteiros sem decimais | `int age = 25;` ou `int num = -12;` |
| double | Armazena números de ponto flutuante com decimais | `double price = 19.99;` ou `double pi = 3.14159;` |
| float | Armazena números de ponto flutuante com precisão menor que double | `float temperatura = 36.5f;` ou `float pi = 3.14159f;` |
| char | Armazena um único caractere | `char letra = 'A';` ou `char letra = 65;` |
| string | Armazena uma sequência de caracteres (texto) | `string nome = "Eddy";` |
| bool | Armazena valores com dois estados (true/false) | `bool ativo = true;` |


## <font color="gree">Identificadores em C++</font>
Todas as variáveis ``​​C++`` devem ser identificadas com nomes exclusivos. Esses nomes exclusivos são chamados de identificadores.

Os identificadores podem ser nomes curtos (como ``x`` e ``y``) ou nomes mais descritivos (``age``, ``soma``, ``volume_total``).

**Nota:** É recomendável usar nomes descritivos para criar um código compreensível e sustentável.

As regras gerais para nomear variáveis ​​são:

* Os nomes podem conter letras, dígitos e sublinhados
* Os nomes devem começar com uma letra ou um sublinhado (``_``)
* Os nomes diferenciam maiúsculas de minúsculas ( ``myVar`` e ``myvar`` são variáveis ​​diferentes)
* Os nomes não podem conter espaços em branco ou caracteres especiais como ``!``, ``#``, ``%``, etc.
* Palavras reservadas (como palavras-chave ``C++``, como ``int``) não podem ser usadas como nomes


## <font color="gree">Constantes em C++</font>
Quando você não quiser que outros (ou você mesmo) alterem valores de variáveis existentes, use a palavra-chave ``const`` (isso declarará a variável como ``"constante"``, o que significa imutável e somente leitura).
