`C++` é uma linguagem de programação de propósito geral criada em 1983 por Bjarne Stroustrup como uma extensão da `linguagem C`. Ela foi desenvolvida para incluir o `paradigma de programação orientada a objetos`, além de manter o acesso a recursos de baixo nível, típicos do `C`, como o uso de ponteiros.
